# Klussen in Frankrijk — archief Christian von Klösterlein

[Bekijk de actuele V07-website](https://klussen-in-frankrijk.antonnoe.chatgpt.site)

Dit project reconstrueert de voormalige website **klusseninfrankrijk.eu** van
Christian von Klösterlein. Na het verdwijnen van de oorspronkelijke
Weebly-website bleven 125 PDF-bestanden met teksten en afbeeldingen bewaard.
Deze vormen de bron voor de nieuwe website.

## Status

Dit is **V07**: een omvangrijke reconstructieversie, nog geen definitieve V1.0.

- De oorspronkelijke teksten worden integraal overgenomen.
- De persoonlijke en anekdotische schrijfstijl van de auteur blijft behouden.
- Afbeeldingen worden teruggeplaatst bij de bijbehorende tekstpassages.
- Inhoudelijke actualisering en technische controle volgen pas nadat de
  reconstructie van de volledige website is afgerond.

De informatie is deels vele jaren oud. Materialen, productnamen, normen,
veiligheidsvoorschriften en Franse regelgeving kunnen inmiddels veranderd zijn.
V07 is daarom een **historisch werkarchief**, niet zonder meer actueel
klusadvies.

## Wat is al beschikbaar?

De website bevat een groeiende verzameling gereconstrueerde artikelen, waaronder:

- Wanden van gipsplaten;
- Uitgezakte luiken weer in vorm brengen;
- Alles in huis is scheef;
- Betegelen van oude vloeren;
- Condensproblemen bij dakramen;
- Dakbuitenisolatie;
- Deuren opknappen;
- Gaten in hout opvullen;
- De keuze van een raam;
- Krakende vloeren;
- Standaardgereedschappen.

Het uitgebreide artikel **Wanden van gipsplaten** omvat 23 bronpagina’s,
ruim 8.000 woorden en 61 oorspronkelijke afbeeldingen. De afbeeldingen zijn
tussen de bijbehorende tekstpassages geplaatst.

## Repository en website

Deze repository bevat de volledige broncode en de lokale bronafbeeldingen van
de website. GitHub toont deze bestanden als mappen en code; de visueel
gerenderde website staat op:

**https://klussen-in-frankrijk.antonnoe.chatgpt.site**

De voornaamste onderdelen van de broncode:

- `app/page.tsx` — startpagina en archiefoverzicht;
- `app/artikelen/` — de gereconstrueerde artikelen;
- `public/articles/` — de bijbehorende bronafbeeldingen;
- `app/globals.css` — de volledige visuele vormgeving.

## Vervolg

De resterende PDF’s worden batchgewijs verwerkt. Per artikel bestaat dat proces
uit:

1. integrale tekstextractie;
2. herstel van afgebroken zinnen en paginaovergangen;
3. koppeling van afbeeldingen aan de juiste tekstpassages;
4. controle op volledigheid ten opzichte van de PDF;
5. publicatie als nieuw webartikel.

Pas wanneer de reconstructie compleet is, volgt de inhoudelijke audit en
actualisering richting **V1.0**.
